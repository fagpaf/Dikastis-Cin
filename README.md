# Introdução à Programação (Dikastis-Cin)

Este repositório armazena os códigos, exercícios e resoluções desenvolvidos durante a cadeira de Introdução à Programação. O material está organizado de forma sequencial, acompanhando a progressão dos conceitos fundamentais de lógica de programação.

## Estrutura de Diretórios

Os arquivos estão divididos pelos principais assuntos abordados na disciplina, todos implementados em Python:

* **0. Lista de Treinamento:** Exercícios básicos de nivelamento e familiarização com a sintaxe (ex: *Tamanho da caverna.py*, *Competição.py*).


* **1. Comandos Condicionais:** Práticas de lógica de decisão utilizando `if`, `elif` e `else` (ex: *The Witches Are Back.py*, *Uma Noite de Crime.py*).


* **2. Laços de Repetição:** Algoritmos iterativos e controle de fluxo com `for` e `while` (ex: *The Eras Tour.py*, *A Batalha das Divas.py*).


* **3. Listas:** Manipulação de arrays, iteração e gerenciamento de estruturas de dados lineares (ex: *Percy Jackson e o EDEM!!!.py*, *Organização do Acampamento Meio-Sangue.py*).


* **4. Funções:** Modularização de código, passagem de parâmetros e retorno de valores (ex: *Os Vagões das Funções Mágicas.py*, *Missão para salvar o natal.py*).


* **5. Recursão:** Resolução de problemas utilizando funções que chamam a si mesmas (ex: *Matrix.py*, *Keanu Reaves.py*).


* **6. Tuplas e Dicionários:** Mapeamento de chave-valor e estruturas imutáveis (ex: *Sabores de Recife.py*, *O Show do Sambódromo.py*).



## Ferramentas e Avaliação (Monitoria)

* **Feedbacks:** Diretório organizado por listas (L1 a L6) contendo arquivos `.md` com as avaliações e retornos sobre as submissões de código.


* **Monitoria:** Arquivos auxiliares (`debug.py`, `sample.py`, `input.txt`) utilizados para depuração, testes e validação das lógicas implementadas.


* **.vscode:** Configurações de ambiente de desenvolvimento, execução (`launch.json`) e tarefas locais.



## Tecnologias

* **Linguagem:** Python


* **Ambiente:** Visual Studio Code
