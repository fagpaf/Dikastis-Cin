## Sugestões de Melhoria
1. **Declaração de variáveis em Python:**  
   Não é necessário usar `str()`, `int()`, ou outras conversões na declaração inicial de variáveis, pois em Python isso já é feito dinamicamente por padrão.  
   - **Exemplo:**  
     Em vez de:
     ```python
     nome = str()
     ```
     Use:
     ```python
     nome = ""
     ```
   Essa prática mantém o código mais limpo, principalmente em exercícios mais longos. No entanto, se preferir continuar declarando desse jeito, não tem problema, mas eu sugiro evitar para simplificar!

2. **Comentários no código:**  
   Mesmo que agora os códigos sejam relativamente simples, acostume-se a adicionar comentários. Eles ajudam:
   - Outras pessoas a entenderem sua lógica.
   - Você mesma a retomar um código antigo e rapidamente lembrar o que cada parte faz.  
   
   - **Exemplo de comentário útil:**
     ```python
     # Verifica se o número é par ou ímpar
     if numero % 2 == 0:
         print("Par")
     else:
         print("Ímpar")
     ```
